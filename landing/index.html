Lappu

A native Nextcloud Notes client for Sailfish OS - write in Markdown, browse by category, and keep writing when the server is out of reach.

Documentation GitHub
Releases Translate Donate

What you can do

  • Notes written in Markdown
  • Emphasis, headings, lists and links from one bar
  • Categories, favourites and full text search
  • Task lines ticked from the note itself
  • Offline edits, sent by the next sync
  • One note kept on the cover
